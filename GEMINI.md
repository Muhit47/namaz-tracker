# Instructions for Code Execution via Kilo Desktop

- Always break down any coding or implementation request into small, atomic, step-by-step micro-tasks.
- Never write large chunks of code or give big combined prompts at once.
- For each micro-task:
  1. State what this step accomplishes in 1-2 lines.
  2. Provide a single, concise, laser-focused prompt formatted in a code block specifically crafted for Kilo Desktop.
  3. Ensure the prompt has zero ambiguous context and focuses on only one file or function at a time.
- Stop and wait for the user to confirm execution or share results before proceeding to the next step.
